# 6. Idea catalogue

Every idea worth keeping, sorted by system. Each has an ID, a kind (**A**dd something new, **I**mprove something that
exists, **C**onnect two systems), and where it lives: a round (R-number, specced in [rounds/](rounds/)) or **free** (not
in a round yet: pick it up as a ride-along or grow a round from it). When an idea ships, strike it and name the PR.

Kinds at a glance: a system with few **C** ideas is an island; a system with only **I** ideas is done growing.
