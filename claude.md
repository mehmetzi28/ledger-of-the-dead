Ledger of the Dead: single-file HTML/CSS/JS necromancer RPG.
- index.html is the shipped game, generated from src/ and committed; never edit it by hand. Edit files in `src/`, then run `node tools/build.js` (each `@@include` line in the template becomes that file's exact bytes). `node tools/build.js --check` fails if index.html differs from src/ (run-tests.js and CI run it first). serve.js rebuilds automatically when a src file is newer, so edit and refresh.
- Design docs live in `docs/design/` (vision, every system, how systems connect with a numbered gap list, balance targets and measurements, and the prioritized roadmap of big rounds). Start each round there, and update the touched sections (02 systems, 03 gaps, 04 measurements, 05 roadmap status) in the same PR.

- Tests: `node tests/run-tests.js` runs 855 tests (one file per system in tests/groups/, helpers and runner in tests/game-tests.js, plus a 30-day bot playthrough) against the built index.html in Node with a fake browser; add `market` etc. to run matching tests. Run it after every change. It first checks the build, then runs tests/lint.js on src/*.js, which fails if a `//` comment was dropped into the middle of a one-line statement and swallowed the code after it (put mid-line notes in `/* */` or at the end of the line), or if a stray control character got into a src file. In the browser: load tests/game-tests.js, then `await LOTD_TESTS.load(); LOTD_TESTS.run()`. GitHub Actions runs it on every push. A second server for play-testing with separate saves: `node tools/serve.js 5174` (launch config "playtest"); a third, "scratch" on 5175, is for throwaway visual checks that must not touch either save (a tab on the same port as a game in use makes that game stop saving).
- Fuzzing: `node tests/fuzz.js` clicks random buttons for thousands of steps per seed and checks the same rules after every click; run it after big changes. Don't edit or rebuild index.html while it runs, because each seed reloads the file.

New UI text needs a Turkish entry there; text with names in it uses a pattern in `TR_RX` (names stay English, $n keeps a group, {tn} translates it). Boss speech is translated through a pattern too.
- Libraries only as vendored files in lib/ (now PixiJS 8.23.0, for the battle effects layer in src/fx.js, loaded at runtime); no CDNs except Google Fonts. The game and the tests must work with the library absent.
- Line endings are LF everywhere (.gitattributes). Write files with LF.
