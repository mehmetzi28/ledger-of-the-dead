Ledger of the Dead: single-file HTML/CSS/JS necromancer RPG.
- Game logic is above the `//==UI==` marker; UI and icons below it.
- Saves use localStorage key `ledger-of-the-dead-v1`. Keep loadGame backward compatible: every load goes through normalizeSave (repairs/migrates) and applyLoaded.
- Browsers block localStorage on data: pages, so test saves with `node tools/serve.js` (http://localhost:5173, launch config "game").
- Difficulty is tuned with the DIFF block (gates) and the TW constants (Hell Tower). Balance was tested with bots only. The bot lives in tests/balance-test.js: paste it into the browser console with the game open, or load it from the local server (see the top of the file), then run LOTD_BALANCE.run({modes:['market']}). Faster: `node tests/run-balance.js` (options as JSON, e.g. '{"seed":9100}'). The 'full' mode (`'{"modes":["market","full"]}'`) also uses buildings, salvage, enchanting, fusion, bounties and orders; it should land a little above 'market' (about 84-88% per gate vs about 80%). `"off":["fuse"]` switches parts off to measure them.
- Tests: `node tests/run-tests.js` runs 322 tests (one file per system in tests/groups/, helpers and runner in tests/game-tests.js, plus a 30-day bot playthrough) against index.html in Node with a fake browser; add `market` etc. to run matching tests. Run it after every change. In the browser: load tests/game-tests.js, then `await LOTD_TESTS.load(); LOTD_TESTS.run()`. GitHub Actions runs it on every push. A second server for play-testing with separate saves: `node tools/serve.js 5174` (launch config "playtest").
- Fuzzing: `node tests/fuzz.js` clicks random buttons for thousands of steps per seed and checks the same rules after every click; run it after big changes. Don't edit index.html while it runs, because each seed reloads the file.
- Dark palette. Blue and purple are only for the Rare and Epic item tiers.
- No external libraries except Google Fonts.
- Line endings are LF everywhere (.gitattributes). Write files with LF.
